# 1.0.3

- 15개 레슨을 각각 영어 음성이 포함된 Momo 캐릭터 영상으로 제작하고 영상별 프리뷰 이미지와 실제 재생 시간을 표시합니다.
- `/watch/[id]` 시청 페이지, 직접 접근, 새로고침, 관련 영상 이동과 404 처리를 추가합니다.
- 목록 복귀와 브라우저 뒤로가기에서 탐색 상태 및 스크롤 위치를 복원합니다.
- 속도·영어/한국어 자막·챕터·문장·대화 구간 이동을 제공하며 저장·완료·퀴즈 기능을 유지합니다.
- 런타임 Web Speech 의존성을 제거하고 실제 MP4 재생, 미디어 무결성, 탐색 및 회귀 동작을 검증합니다.
