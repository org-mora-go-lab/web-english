# 1.0.8 · 메일 없는 즉시 가입

- 이메일과 비밀번호로 가입하면 즉시 계정을 활성화하고 로그인합니다.
- 인증 메일, 재설정 메일, 미사용 토큰 테이블을 제거했습니다.
- 이메일 변경은 현재 비밀번호를 확인하고 모든 기존 세션을 무효화합니다.
- 중복 가입이 기존 계정의 비밀번호를 바꾸지 않는지 E2E로 확인합니다.
- 가입·모바일 글 편집·학습 진도 흐름을 모바일 WebKit에서도 검증합니다.
- 메일 없이 운영하므로 비밀번호 분실 시 계정 복구를 제공하지 않습니다. 향후 카카오 로그인은 검증되지 않은 이메일만으로 기존 계정과 연결하지 않습니다.
