# 1.0.14

- 부모용 영어 놀이와 일상 회화를 위한 OpenAI 대화 화면 `/ai`를 추가합니다.
- 웹에서 GPT-6 Luna, Sol, Astra를 선택하며 마지막 모델 선택을 기억합니다.
- 기존 회원 인증과 서버 전용 API 키, 요청 검증 및 계정별 사용 제한을 적용합니다.
- 대화 재시도·중지·새 대화와 연결 상태 안내를 제공합니다.
- API 키가 없는 환경은 연결 준비 상태를 표시하며 실제 응답을 가장하지 않습니다.
- 자동 테스트는 실제 OpenAI 호출 없이 UI 및 API 보호 동작을 검증합니다.
- E2E는 별도 로컬 DB와 운영 빌드로 실행하며 Windows에서도 동일한 검증 절차를 지원합니다.
