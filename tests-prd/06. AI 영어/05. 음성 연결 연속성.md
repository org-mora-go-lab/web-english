# 음성 연결 연속성

1. 서버의 저장·제어 연결 갱신은 같은 WebRTC·오디오·마이크를 유지하며 새 OpenAI call 생성이나 마이크 권한 재요청 없이 완료한다. 갱신 전후 같은 대화와 표시된 내역을 유지한다.
2. 자동 갱신 뒤에도 마이크 음소거 상태를 유지하며 연결 진행 상태와 음소거 안내를 함께 표시한다.
3. 갱신 요청 중 종료하면 마이크를 해제하고 늦은 연결로 다시 시작하지 않는다.
4. 100회가 넘는 대화에서도 음성을 시작할 수 있으며 서버는 해당 버전을 유효하게 처리한다.
5. 다른 계정의 연결을 이용한 갱신 요청을 거절한다.
6. 사용자가 직접 종료한 연결의 갱신 요청을 거절한다.
7. 이미 갱신에 사용한 연결의 재사용 요청을 거절한다.

저장·제어 연결은 약 2분마다 다음 sideband를 먼저 연결한 뒤 처리 중인 전사·답변 상태와 최근 이벤트 ID를 전달하고 이전 sideband만 닫는다. 같은 이벤트가 두 연결에서 관측되어도 한 번만 저장한다. 브라우저 마이크·오디오는 갱신 중 비활성화하거나 일시 정지하지 않는다. 장시간 OpenAI call 교체는 같은 계정·대화·모드와 1회 사용 부모 ID를 검증하고 미리 준비한 연결로 전환한다. 직접 종료한 연결과 이미 사용한 부모 ID는 재사용할 수 없다. 새 음성 시작만 기존 요청 쿼터를 차감한다. OpenAI 크레딧·속도 제한과 실제 네트워크 오류는 계속 적용되며 사용자의 종료·화면 이탈·인증 만료 시 종료한다.
