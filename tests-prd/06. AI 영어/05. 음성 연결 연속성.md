# 음성 연결 연속성

1. 서버가 연결 갱신을 알리면 재시작 버튼 없이 같은 대화 ID·최신 저장 버전·모드·목소리로 자동 연결하며 마이크 권한을 다시 요청하지 않는다. 이 과정에서 이전 WebRTC 연결이 닫혀도 대화를 종료하지 않는다.
2. 자동 갱신 뒤에도 마이크 음소거 상태를 유지하며 연결 진행 상태와 음소거 안내를 함께 표시한다.
3. 갱신 요청 중 종료하면 마이크를 해제하고 늦은 연결로 다시 시작하지 않는다.
4. 100회가 넘는 대화에서도 음성을 시작할 수 있으며 서버는 해당 버전을 유효하게 처리한다.
5. 다른 계정의 연결을 이용한 갱신 요청을 거절한다.
6. 사용자가 직접 종료한 연결의 갱신 요청을 거절한다.
7. 이미 갱신에 사용한 연결의 재사용 요청을 거절한다.

갱신 허가는 서버가 정상적인 교체를 마친 연결에만 부여하며 동일 계정·대화·모드 및 짧은 유효 시간과 1회 사용을 검증한다. DB의 갱신 부모 ID 고유 인덱스와 계정당 활성 연결 고유 인덱스로 경합을 차단한다. 새 음성 시작은 기존 요청 쿼터를 적용하고 자동 갱신은 중복 차감하지 않는다. OpenAI의 크레딧·속도 제한과 네트워크 오류는 계속 적용된다. 마이크는 발화 및 응답을 마친 뒤 갱신 동안만 잠시 비활성화하며 사용자의 종료·화면 이탈·인증 만료 시 자동 갱신하지 않는다.
