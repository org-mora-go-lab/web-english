# 대화 저장

1. 로그인한 계정의 최신 대화를 새로고침해도 불러오고, 같은 대화 ID와 버전으로 이전 문맥을 포함하여 이어간다.
2. 다른 계정의 대화는 목록에 보이지 않으며 조회·삭제·이어가기 요청을 거절한다.
3. 내 대화를 삭제하면 새로고침해도 복원하지 않는다.
4. 비회원의 대화 목록·개별 조회·삭제 요청을 거절한다.
5. 이전 버전의 대화 요청은 409로 거절하고 저장된 메시지를 덮어쓰지 않는다.
6. 계정 탈퇴는 해당 계정의 AI 대화도 삭제한다.

완료된 질문과 답변을 함께 저장하며 API 실패·취소는 완료된 대화로 저장하지 않는다. 동일한 마지막 요청 ID의 재시도는 저장된 결과를 반환한다. 대화당 최대 100회 왕복을 보관하고 최근 문맥 최대 18개 메시지·10,000자를 다음 질문에 포함한다. 목록은 최신 100개 대화를 보여준다. 테스트는 로컬 DB에 대화를 준비하고 실제 계정 API를 사용하며 실제 OpenAI 호출은 하지 않는다.
