# AI 대화

1. 로그인한 사용자의 AI 대화 화면은 상단 소개 영역 없이 화면 높이를 채우고 입력창을 하단에 유지한다. 텍스트 모델과 목소리는 입력창 하단에서 선택하며 대화 모드·내역은 왼쪽 사이드바에서 확인하고, 모델을 선택해 보낸 요청의 답변과 모델명을 확인한다.
2. 모델 선택은 새로고침 후에도 복원한다.
3. 응답 오류가 발생하면 입력을 유지하며 다시 보내기로 같은 요청을 재시도해도 대화에 사용자 메시지를 중복 추가하지 않는다.
4. 응답 중지는 글자 없이 사각형 아이콘으로 표시하고 접근성 이름을 유지한다. 버튼을 누르면 진행 중인 요청을 취소하고 입력을 유지하며, 취소한 요청의 늦은 응답이 이후 대화에 추가되지 않는다.
5. 새 대화를 시작하면 이전 대화 내용을 지우고 다음 요청에는 새 대화만 포함한다.
6. 부모 영어 놀이에서 영어 회화 연습으로 바꾸면 이전 대화 내용을 지우고 다음 요청에는 변경한 모드와 새 대화만 포함한다.
7. 스마트폰 너비에서 첫 화면의 AI 영어 도우미 링크로 대화 화면에 진입하고 브라우저 뒤로가기로 첫 화면에 복귀한다.
8. 비회원에게는 로그인 안내만 표시하고 모델 선택·입력창을 숨기며 AI API를 호출하지 않는다. 로그인한 뒤 AI 대화 화면으로 복귀하여 메시지를 입력할 수 있다.
9. API 연결이 미설정 상태이면 안내와 함께 입력을 비활성화하고, 연결 상태를 다시 확인하여 설정 완료가 확인되면 대화를 시작할 수 있다.
10. 빈 입력창에서 Tab을 누르면 현재 모드의 placeholder 추천 질문을 입력하고 초점을 유지한다. 기존 입력이 있거나 Shift+Tab을 누르면 입력을 바꾸지 않고 초점을 이동하며 자동 전송하지 않는다.

UI 테스트는 실제 로컬 회원 세션을 사용하되 `/api/ai/models`와 `/api/ai/chat`을 브라우저에서 대체한다. 실제 OpenAI 응답 품질이나 과금·사용량을 검증하는 테스트가 아니다. 완료된 대화는 계정별 서버에 저장하며 저장과 접근 제한은 별도 대화 저장 요구사항으로 검증한다.
