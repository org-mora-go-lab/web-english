# 순차 응답

1. 답변 생성 중에는 도착한 텍스트를 채팅 안에 순차 표시한다. 완료 전에는 완성된 답변으로 추가하지 않고 완료 후에는 추천 답변과 함께 한 번만 반영한다.
2. 순차 표시 중 중지하면 임시 응답을 제거하고 질문을 남긴다. 취소한 요청의 후속 조각은 새 대화에 섞이지 않는다.
3. 서버는 OpenAI의 텍스트 조각만 공개 스트림으로 전달하고 완성된 답변·추천 문장만 계정 DB에 함께 저장한다. 같은 턴 재요청은 저장된 결과를 재사용하며 새 API 호출을 하지 않는다. 한글·이스케이프·유니코드가 잘린 전송 경계에서도 본문에 JSON 메타데이터를 노출하지 않는다.
4. 스트림 소비를 취소하면 서버가 외부 생성 요청도 취소하고 미완성 대화를 저장하지 않는다.
5. 완료 이벤트 없이 스트림이 끊기면 안전한 오류를 반환하고 저장하지 않는다. 같은 턴 재시도는 정상 완료한 질문·답변 한 쌍만 저장한다.

순차 응답은 OpenAI Responses API의 공식 스트리밍을 사용한다. 추천 문장은 같은 생성 요청의 구조화된 응답에서 함께 받는다. 음성 연결과 저장 방식은 유지한다. UI와 서버 프로토콜 테스트 모두 외부 API를 대체하므로 실제 API 과금이 발생하지 않는다.
