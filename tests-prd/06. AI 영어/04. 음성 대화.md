# 음성 대화

1. 사용자가 음성 대화를 시작하면 인식된 문장을 자동 전송하고 AI 답변을 읽은 뒤 마이크를 다시 열어 이전 문맥으로 대화를 이어간다.
2. 마이크 권한이 거절되면 안내하고 음성 대화를 종료하며 자동 요청을 보내지 않는다.
3. 음성 인식을 지원하지 않는 브라우저에서는 음성 시작을 비활성화하고 텍스트 대화를 제공한다.
4. 음성 종료 후 늦은 인식 이벤트는 무시하고 메시지를 자동 전송하지 않는다.

영어 회화 모드는 en-US, 부모 놀이 모드는 ko-KR로 인식하고 읽는다. 음성은 브라우저 제공 서비스로 전송될 수 있음을 시작 전에 안내한다. 마이크는 사용자의 시작 조작 후에만 열고, 화면 숨김·이탈·대화 전환·오류 때 종료한다. 인식과 합성은 모의 브라우저 API로 검증하며 실제 기기 마이크의 인식 품질은 브라우저와 환경에 따라 다르다.
