# 음성 대화

1. 사용자가 고급 음성을 시작하면 WebRTC로 연결하고 서버가 저장한 사용자 전사문·AI 답변을 화면에 반영한다. 음성 중에는 텍스트 전송을 잠근다.
2. 마이크 권한이 거절되면 안내하고 OpenAI 연결 요청을 보내지 않는다.
3. WebRTC를 지원하지 않는 브라우저에서는 고급 음성 시작을 비활성화하고 텍스트 대화를 제공한다.
4. 종료 시 오디오 트랙·연결을 정리하고 서버 종료 API를 호출하며 늦게 도착한 이벤트를 무시한다.
5. 마이크 음소거·해제를 오디오 트랙에 반영한다.
6. 화면이 숨겨지면 마이크와 고급 음성을 종료한다.
7. 서버가 연결 오류 등으로 종료를 알리면 안내하고 텍스트 대화를 다시 허용한다.
8. 닫힌 목소리 선택은 고양이·여자·남자로 표시하고 드롭다운 옵션에는 전체 설명을 표시한다. 고양이(부드러운 고양이 말투의 Marin), 여자(Marin), 남자(Cedar) 목소리를 선택하여 서버에 전달하며 연결 중에는 변경하지 못한다.

GPT Realtime 2.1이 음성을 직접 입력·출력하고 의미 기반 발화 감지와 끼어들기를 사용한다. 서버 영어 코치 에이전트 지침과 저장된 최근 문맥을 연결 생성 시 제공한다. 서버가 OpenAI sideband에서 받은 전사문과 완료된 답변만 계정 내역에 저장하며 취소된 답변은 저장하지 않는다. 3분·10회·100회 종료 제한 없이 이어간다. 서버리스 저장·제어 요청의 갱신은 WebRTC 음성 연결에 영향을 주지 않는다. OpenAI 자체의 최대 60분 세션은 55분부터 다음 WebRTC를 무음으로 준비한 뒤 발화·답변 재생·저장이 완료된 자연스러운 턴 경계에서 전환한다. 준비 중에도 기존 마이크와 오디오는 계속 작동하고 전환 뒤 이전 call을 hangup한다. 오류·인증 만료·화면 이탈은 종료한다. 음성은 OpenAI로 전송되고 API 요금과 AI 생성 음성임을 안내한다. 자동 테스트는 WebRTC·장치·서버 스트림을 대체하고 실제 연결 및 갱신도 별도 실서비스에서 확인한다.
