# 비회원 채팅

1. 비회원 홈은 로그인·회원가입 안내 화면만 표시하며, 채팅 입력창·새 채팅·콘텐츠 사이드바를 렌더링하거나 AI API를 호출하지 않는다.
2. 비회원이 레슨 목록 `/library`에 접근해도 목록과 검색 대신 로그인 안내만 표시한다. 학습 데이터 API를 호출하지 않으며 로그인 링크에 원래 경로를 유지한다.
3. 비회원이 `/watch/[id]` 영상 주소로 직접 접근해도 영상 플레이어와 채팅 대신 로그인 안내만 표시하고, 로그인 링크에 영상 경로를 유지한다.
4. 비회원이 글 목록·상세·공개 컨텍스트 주소로 직접 접근해도 본문 대신 로그인 안내를 먼저 표시하고 로그인 링크에 원래 경로를 유지한다. 기존 공개 읽기 API의 권한 범위는 유지한다.

로그인 안내에는 고양이 이미지와 부모를 위한 짧은 설명을 제공한다. 대화·음성·콘텐츠 탐색·놀이 기록·프로젝트 조작은 로그인한 사용자만 이용한다. `/ai`의 로그인 유도와 로그인 후 복귀는 AI 대화 8번 요구사항에서 검증한다.
