# API 보호

1. 로그인하지 않은 사용자의 대화 요청을 401 응답으로 거절한다.
2. 로그인한 사용자가 허용 목록 밖의 모델을 요청하면 400 응답으로 거절한다.
3. 로그인한 사용자가 서버 지침으로 취급되는 system 역할을 요청 본문에 넣으면 400 응답으로 거절한다.
4. 외부 출처에서 보낸 대화 요청을 403 응답으로 거절한다.
5. 서버 API 키가 설정되지 않았으면 유효한 회원 대화 요청을 503 응답으로 종료하고 공개 오류 코드로 안내한다.
6. 모델 목록 API는 비회원에게 캐시하지 않는 401 응답을 반환하고, 회원에게만 모델을 제공하며 로그아웃하면 다시 차단한다.
7. 고급 음성 시작·종료 API는 비회원 요청을 401로 거절한다.
8. 고급 음성 시작 API는 외부 출처 요청을 403으로 거절한다.
9. API 키가 없으면 고급 음성 연결 전에 503으로 종료한다.
10. 다른 계정이 소유한 음성 연결은 종료할 수 없으며 404로 처리한다.

이 테스트들은 대체 응답 없이 실제 로컬 API를 호출한다. E2E 서버의 `OPENAI_API_KEY`를 빈 값으로 고정하여 외부 API 호출과 과금을 방지한다. API 키와 내부 오류 내용은 회원용 설정 조회에도 포함하지 않는다. 운영 환경은 계정별·전체 사용량 제한을 적용하고 자동 재시도 없이 요청을 처리한다.
