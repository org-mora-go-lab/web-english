# 대화 그룹

1. 사이드바에서 이름을 입력해 프로젝트를 만들면 새로고침 후에도 계정에 저장된 프로젝트를 표시한다.
2. 프로젝트 이름을 변경하면 새로고침 후에도 변경된 이름을 표시한다.
3. 대화 메뉴에서 프로젝트를 선택해 대화를 이동하면 새로고침 후에도 같은 그룹에 유지된다.
4. 프로젝트 삭제는 대화를 삭제하지 않으며 기존 대화는 미분류로 돌아간다.
5. 사이드바 대화 메뉴에서 삭제한 대화는 목록과 서버 저장 데이터에서 제거된다.

프로젝트는 계정별 Turso 데이터로 관리한다. 프로젝트 생성·수정·삭제와 대화 이동은 기존 대화 및 고급 음성 기능과 별개로 요청 성공 후 반영한다. 삭제 전에는 어떤 데이터가 삭제되는지 확인한다.
6. 대화 삭제·프로젝트 변경 요청 중에는 새 채팅·메시지 전송을 잠가 늦은 응답이 새 대화를 지우거나 그룹 이동 결과를 덮어쓰지 못하게 한다.
