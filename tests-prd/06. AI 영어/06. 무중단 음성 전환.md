# 무중단 음성 전환

1. AI 답변 재생 중 저장 연결이 갱신되어도 같은 오디오와 마이크가 유지되고 이후 전사문·저장 답변을 표시한다.
2. 장시간 세션의 다음 WebRTC가 먼저 연결되어도 현재 답변과 마이크를 유지하며, 답변 재생·저장이 끝난 뒤 송신자를 전환한다.
3. 다음 연결을 준비하는 동안 대화가 추가되면 최신 저장 버전으로 문맥을 갱신하고 오래된 문맥으로 전환하지 않는다.
4. 다음 음성 연결을 준비하는 중 사용자가 종료하면 현재·대기 연결과 마이크를 모두 정리한다.
5. 비회원의 저장 연결 갱신 및 대기 연결 제어 요청은 인증 오류로 거절한다.
6. 외부 출처의 저장 연결 갱신 및 대기 연결 제어 요청은 거절한다.
7. 다른 계정의 저장 연결 갱신 및 대기 연결 제어 요청은 거절한다.
8. 저장 연결 갱신과 대기 연결 제어의 잘못된 JSON과 크기 초과 요청은 외부 호출 전에 거절한다.
9. 서버는 진행 중인 질문·답변의 상태를 다음 sideband에 전달하고 겹쳐 수신한 이벤트를 중복 저장하지 않는다.
10. 서버는 현재 call을 유지한 채 다음 call을 준비하고 최신 문맥 검증을 거쳐 활성화하며, 다음 call도 같은 계정 대화에 저장한다.

일반 갱신은 서버의 다음 sideband가 먼저 수신을 시작한 다음 이전 sideband의 처리 대기열·중복 제거용 이벤트 ID·진행 중 전사/답변 상태를 전달한다. 오디오 WebRTC는 교체하지 않는다. 장시간 세션은 다음 WebRTC의 송신 트랙을 비워 둔 채 준비하고, 최신 문맥 설정을 서버가 확인한 뒤 입력·답변·재생·저장이 모두 끝난 지점에서 트랙을 옮긴다. 음성 입력을 받기 전부터 대기 연결이 서버 프롬프트를 갱신하며 원본 마이크 트랙을 중지하거나 비활성화하지 않는다. 전환 후 이전 call을 종료한다. 서버 프로토콜 검증은 별도 로컬 DB와 가짜 OpenAI 소켓으로 실행하며 실제 API 키나 비용을 사용하지 않는다.
