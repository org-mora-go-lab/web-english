# 사이드바 고정 헤더

1. 홈 사이드바가 열리면 바깥 메뉴 버튼을 숨긴다. 사이드바에는 모라 아이콘·Mora와 별도 접기 아이콘을 배치하며 본문을 스크롤해도 46px 상단 헤더와 닫기 조작을 고정한다.
2. AI 대화 화면에서도 사이드바가 열리면 메뉴 버튼을 숨기고 모라 아이콘·Mora·접기 아이콘을 고정하며 본문만 스크롤한다.
3. 배포용 빌드에서도 채팅 상하단 fog의 흐림 처리가 실제 브라우저에 적용되며 입력과 클릭을 막지 않는다.

채팅 내용의 상하단 fog는 라이트·블랙 테마 배경에 맞춰 흐려지며 클릭을 차단하지 않는다. 전체 글자 크기는 기존보다 1px 키운다. 이 시각 사양은 PC·모바일 육안 검증으로 확인하고, 기존 콘텐츠 탐색·하단 입력·목소리 선택 E2E를 함께 수행한다.
