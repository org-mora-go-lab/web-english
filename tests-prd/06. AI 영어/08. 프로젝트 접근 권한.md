# 프로젝트 접근 권한

1. 프로젝트 목록은 로그인한 계정 소유의 프로젝트만 반환한다.
2. 다른 계정의 프로젝트 이름 변경은 404로 거절하며 원래 이름을 보존한다.
3. 다른 계정의 프로젝트 삭제는 404로 거절하며 프로젝트를 보존한다.
4. 다른 계정의 대화를 자신의 프로젝트로 이동하는 요청은 404로 거절한다.
5. 자신의 대화를 다른 계정의 프로젝트에 붙이는 요청은 404로 거절한다.
6. 비회원의 프로젝트 목록 조회는 401로 거절한다.
7. 비회원의 프로젝트 생성은 401로 거절한다.
8. 외부 출처에서 보낸 프로젝트 생성 요청은 403으로 거절하며 데이터를 만들지 않는다.

권한 검사는 서버의 모든 프로젝트·대화 이동 API와 데이터 접근 계층에서 수행한다. 실패한 이동은 기존 프로젝트 관계를 변경하지 않는다.
