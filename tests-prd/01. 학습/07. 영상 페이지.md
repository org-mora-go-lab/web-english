# 영상 페이지

1. 15개 콘텐츠 목록은 영상의 프리뷰 이미지와 실제 재생 시간을 표시한다.
2. 영상 카드를 클릭하면 고유 URL을 가진 별도 시청 페이지로 전환한다.
3. 브라우저 뒤로가기는 목록의 탭·카테고리·정렬 상태를 복원한다.
4. 영상 URL 직접 접근과 새로고침이 가능하며 목록으로 돌아갈 수 있다.
5. 관련 영상은 해당 시청 페이지로 전환하고 브라우저 뒤로가기로 이전 영상에 돌아갈 수 있다.
6. 모바일 시청 페이지는 첫 화면에 플레이어가 보이고 가로 넘침 없이 목록 복귀가 가능하다.
7. 존재하지 않는 영상 URL은 404를 반환한다.
8. 브라우저 뒤로가기는 목록의 기존 스크롤 위치를 복원한다.
