# 음성 듣기

1. 전체 듣기는 해당 레슨의 핵심 영어 문장 5개를 순서대로 재생한다.
2. 개별 문장 듣기는 선택한 문장만 재생한다.
3. 듣기 속도를 바꾸면 다음 재생에 선택한 속도를 적용한다.
4. 듣기 중지는 현재 음성을 취소하고 재생 상태를 해제한다.
5. 대화 듣기는 영어 대화 문장 4개를 순서대로 재생하고 레슨을 닫으면 음성을 중지한다.
6. 음성 기능을 지원하지 않으면 문장 학습을 계속할 수 있는 안내를 표시한다.
7. 음성 엔진이 오류를 반환하면 안내하고 다시 재생할 수 있는 상태로 복귀한다.
8. 이전 음성의 취소 오류가 늦게 도착해도 새 음성의 재생 상태를 덮어쓰지 않는다.
9. 음성 재생이 8초 이내에 시작되지 않으면 중지하고 기기 음성 설정을 안내한다.
