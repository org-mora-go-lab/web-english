# 나의 라이브러리

1.  레슨 저장 상태는 새로고침 후 유지되며 저장한 레슨 화면에서 취소할 수 있다.
2.  열린 레슨은 최근 학습에 기록되며 새로고침 후 유지된다.
3.  학습 완료 처리한 레슨은 새로고침 후 완료 목록에 표시된다.
4.  완료 취소한 레슨은 새로고침 후에도 완료 목록과 진행률에서 제외된다.
5.  같은 레슨을 다시 열면 최근 학습의 맨 앞으로 이동하며 중복되지 않는다.
6.  다른 창에서 변경한 저장 목록은 열린 창에도 반영된다.
7.  저장 공간을 사용할 수 없으면 세션 내에서는 동작하고 닫을 수 있는 안내를 제공한다.
8.  저장 기록의 잘못된 ID와 중복 ID를 제거하고 유효한 기록만 표시한다.
