# 레슨 탐색

1.  검색어에 해당하는 레슨만 표시하며 일치 항목이 없으면 빈 결과를 안내한다.
2.  카테고리를 선택하면 해당 주제만 표시하고 전체 선택으로 복귀할 수 있다.
3.  모바일에서 가로 넘침 없이 메뉴를 열고 저장한 레슨 화면으로 이동한다.
4.  사이드 메뉴는 홈, 둘러보기, 저장한 레슨, 최근 학습, 완료한 레슨의 정확히 5개 탭으로 구성한다.
5.  검색 버튼 또는 Enter를 누르면 현재 검색 결과의 제목으로 포커스를 이동한다.
6.  카테고리와 난이도를 함께 적용하고 필터 초기화로 모두 해제할 수 있다.
7.  짧은순·제목순 정렬을 선택하면 해당 기준에 따라 결과를 정렬한다.
8.  결과가 없을 때 모든 레슨 둘러보기를 누르면 필터를 해제하고 전체 목록으로 이동한다.
