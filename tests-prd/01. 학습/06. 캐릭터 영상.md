# 캐릭터 영상

1. 홈 첫 화면의 Momo 영상은 실제 MP4를 무음 자동 반복 재생하고 영상 시간이 진행된다.
2. 모바일 첫 화면에서 스크롤하지 않아도 영상 전체가 보이며 가로 넘침이 없다.
3. 목소리 듣기는 음소거를 해제하고 처음부터 재생하며 음소거로 다시 소리를 끌 수 있다.
4. 영상은 일시 정지·다시 재생·시간 이동이 가능하고 표시 상태가 실제 재생 상태를 따른다.
5. 영어 대본과 해석을 펼치면 실제 영상의 문장 4개와 한국어 해석을 읽을 수 있다.
6. 실제 MP4에는 비디오 및 오디오 트랙이 있고 포스터와 영어·한국어 자막 파일이 정상 제공된다.
7. 시청 페이지로 이동하면 홈 인사 영상 플레이어를 해제해 음성이 겹치지 않는다.
8. 영상 로드 실패 시 안내와 비활성화된 목소리 버튼을 표시하고 대본으로 내용을 읽을 수 있다.
