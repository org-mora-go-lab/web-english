# 카카오 로그인

1. 로그인 화면에서 카카오 로그인을 시작하면 닉네임·프로필 사진 동의를 요청하는 카카오 인증 페이지로 이동하며, 기존 이메일 계정과 자동 연결되지 않는다는 안내가 보인다.
2. 로그인한 회원의 프로필 이름과 이미지가 홈과 스튜디오에 표시된다.
3. web-english 세션 쿠키는 고유한 이름과 현재 호스트 범위 및 HttpOnly·SameSite 속성으로 다른 앱 세션과 공유되지 않는다. 명시적으로 설정한 로컬 HTTP 미리보기에서는 일반 쿠키를 사용하며, 배포된 운영 환경은 `__Secure-` 접두사와 Secure 속성을 유지한다.
