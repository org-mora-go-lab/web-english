# 계정 설정

1. 회원은 닉네임을 변경하고 현재 비밀번호 확인 후 로그인 이메일을 변경하여 새 주소로 로그인할 수 있다.
2. 회원이 비밀번호를 변경하면 다른 브라우저의 기존 세션은 보호 API에 접근할 수 없다.
3. 회원 탈퇴 시 공개 글과 계정의 학습 데이터는 삭제된다.

4. 계정 설정 하단에는 밑줄 회원 탈퇴 링크만 표시한다. 누르면 삭제 안내와 확인 입력을 모달 팝업으로 표시하며, 취소·Escape로 닫고 다시 열면 입력을 초기화한다. 팝업을 여닫는 것만으로 탈퇴 API를 호출하지 않는다.
5. 탈퇴 비밀번호가 틀리면 팝업 안에 오류를 표시하고 계정을 보존한다.
