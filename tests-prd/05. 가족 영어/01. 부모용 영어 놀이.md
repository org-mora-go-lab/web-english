# 부모용 영어 놀이

1. 로그인한 부모의 첫 화면은 채팅 안에 고양이를 표시하고 콘텐츠 팝업에서 고른 놀이의 시각 카드와 부모 가이드를 채팅에 표시한다.
2. 현재 개월수는 16~24개월 중에서 선택하며, 한 달마다 서로 다른 놀이를 보여준다. 선택은 새로고침 후에도 계정에서 복원한다.
3. 아이 개월수와 채팅 카드의 놀이 반응·메모를 저장하면 콘텐츠 팝업의 놀이 기록에서 확인하고 삭제할 수 있다.
4. 다른 부모 계정은 해당 기록을 조회하거나 삭제할 수 없다.
5. 부모 가이드는 별도 메뉴 없이 콘텐츠 팝업과 개별 채팅 카드에서 안내하며 따라 말하기·정답을 강요하지 않는 원칙을 설명한다.
6. 모바일 사이드바는 왼쪽에서 오른쪽으로 열리고 너비는 min(308px, 93.5vw)다. 채팅 메뉴와 개월수 선택을 제공하며 가로로 넘치지 않는다.
7. 16~24개월 각각에 서로 다른 놀이 8개씩, 총 72개를 제공한다. 각 개월수는 일상·장난감·그림책·노래·몸짓·산책의 다섯 주제를 포함한다.
8. 고양이 버튼은 클릭할 때만 야옹 효과음을 재생하고 부드러운 인사 동작을 보여준다. 동작 줄이기 설정에서는 애니메이션을 생략한다.
9. 고급 음성 중 콘텐츠 팝업을 여닫아도 같은 음성 연결과 채팅 입력을 유지한다.

개월수는 놀이 편성을 위한 참고이며 아이의 발달 능력을 평가하는 단계가 아니다. 예전 콘텐츠 ID는 저장된 대화·기록에서 계속 읽을 수 있지만 새 목록에는 16~24개월 콘텐츠만 제공한다.
