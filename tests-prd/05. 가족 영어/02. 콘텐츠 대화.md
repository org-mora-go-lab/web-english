# 콘텐츠 대화

1. 놀이 카드를 선택하면 제목·영어 표현·활동 방법·부모 가이드를 포함한 주제로 AI 대화를 시작한다. 이어서 보낸 질문도 같은 대화 ID와 최근 문맥으로 이어진다.
2. 콘텐츠 패널을 여닫아도 채팅과 작성 중인 입력, 선택한 콘텐츠를 유지하며 콘텐츠를 다시 열었다고 AI 요청을 재전송하지 않는다.
3. 주제 대화 요청에 오류가 나면 자동 반복하지 않고 질문을 남긴다. 사용자가 재시도하면 동일한 턴 ID로 보내 중복 저장을 방지한다.
4. 모바일에서도 콘텐츠와 대화 입력창을 함께 표시하고 패널을 닫아도 입력을 보존한다. 가로 스크롤이 생기지 않는다.
5. 고급 음성 중 콘텐츠를 고르면 현재 음성 연결을 유지하고 종료 후 주제 대화를 시작한다.

AI 대화는 기존 인증·요청 제한·계정별 저장 API를 사용한다. 카드 클릭은 AI 요청을 시작하는 동작임을 표시하며, 비회원은 로그인 후 다시 선택한다. 콘텐츠는 모달 대신 독립적으로 스크롤하는 패널에서 확인한다.

6. 새 대화를 시작하면 이전 학습 주제 표시를 해제하고 같은 콘텐츠 질문을 자동으로 재전송하지 않는다. 다른 내역을 열거나 다시 불러올 때도 현재 주제를 해제한다.
