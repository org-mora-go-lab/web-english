# 콘텐츠 대화

1. 놀이 카드를 선택하면 탐색 창을 닫고 채팅 안의 시각 카드와 함께 제목·영어 표현·활동 방법·부모 가이드를 포함한 주제로 AI 대화를 시작한다. 이어서 보낸 질문도 같은 대화 ID와 최근 문맥으로 이어진다.
2. 콘텐츠 탐색 창을 여닫아도 채팅 안의 놀이 카드와 작성 중인 입력을 유지하며 콘텐츠를 다시 열었다고 AI 요청을 재전송하지 않는다.
3. 주제 대화 요청에 오류가 나면 자동 반복하지 않고 질문을 남긴다. 사용자가 재시도하면 동일한 턴 ID로 보내 중복 저장을 방지한다.
4. 모바일에서 콘텐츠 탐색 창을 닫으면 하단 입력창으로 이어갈 수 있다. 창을 여닫아도 작성 중인 문장을 보존하며 가로 스크롤이 생기지 않는다.
5. 고급 음성 중 콘텐츠를 고르면 현재 음성 연결을 유지하고 종료 후 주제 대화를 시작한다.
6. 사이드바에서 새 채팅을 시작하면 이전 학습 주제 표시와 시각 카드를 해제하고 같은 콘텐츠 질문을 자동으로 재전송하지 않는다.
7. 대화 내용은 화면의 남은 높이를 채우고 대화 내역을 스크롤해도 입력창은 화면 하단에 유지한다.
8. 저장된 놀이 대화를 다시 불러오면 해당 놀이의 캐릭터·그림 카드·영어 표현을 채팅 안에 복원하며 AI 요청을 다시 보내지 않는다.
9. 사이드바에서 새 채팅을 만든 뒤 저장된 놀이 대화를 선택하면 해당 대화와 시각 카드로 돌아가 이어갈 수 있다.

AI 대화는 기존 인증·요청 제한·계정별 저장 API를 사용한다. 카드 클릭은 AI 요청을 시작하는 동작임을 표시하며, 비회원은 로그인 후 다시 선택한다. 콘텐츠 탐색과 놀이 기록은 사이드바에서 열고 닫으며 채팅은 전체 높이의 기본 화면으로 유지한다. 고양이와 놀이 시각 요소는 채팅 로그 안에 표시한다.
